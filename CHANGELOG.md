# Changelog

## [0.6.0]

- Highlight only the final Shelly menu block forms, including key modes, keyed options, and blank `shellout ""` rows.
- Add `menu` block indentation and remove obsolete menu directives from generic builtins.

[0.6.0]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.6.0

## [0.5.0]

- Added structured-automation keyword highlighting and indentation for `retry`, `pipeline`, and `parallel` blocks.
- Documented pipeline command-only syntax.

[0.5.0]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.5.0

## [0.4.0]

- Added HTTP `httpPages`, `maxPages`, and `maxTotalBytes` option highlighting.

[0.4.0]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.4.0

## [0.3.0]

- Improved syntax highlighting for mock and secret constructs.

[0.3.0]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.3.0

## [0.2.0] - 2026-10-21

- Added archive v1 syntax highlighting support.

[0.2.0]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.2.0

## [0.1.3] - 2026-10-03

- Improved workspace-aware LSP client behavior.
- Added HTTP syntax highlighting.

[0.1.3]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.1.3

## [0.1.2] - 2026-10-02

- Improved indentation support for watch and wait blocks.

[0.1.2]: https://github.com/Soyagvs/shelly-vscode/releases/tag/v0.1.2
